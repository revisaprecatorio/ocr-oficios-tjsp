## 💡 Lições Aprendadas

### ✅ O Que Funcionou

1. **Exemplos Explícitos no Prompt**
   - Formato tabela com exemplos positivos e negativos
   - Reforço de tipo (NUMBER vs STRING)
   - Ênfase visual com emojis ⚠️❌✅

2. **Validação Implícita no Prompt**
   - "Líquido ≤ Bruto" previne inversão
   - "Valores realistas R$ 1.000 - R$ 10.000.000" detecta problemas
   - "Revise se < R$ 100" captura truncamentos

3. **Abordagem Simples (Opção A)**
   - Modificação direta no prompt
   - Sem quebra de código existente
   - Fácil rollback se necessário

### ❌ O Que Não Funcionou

1. **Herança de Classes Complexas**
   - Tentativa de `ProcessadorOficioV3(ProcessadorOficio)` falhou
   - Acoplamento muito forte
   - Métodos internos incompatíveis

2. **CSV Como "Verdade Absoluta"**
   - CSV tinha os mesmos bugs que o V2.5.1
   - 5 PDFs marcados como "discrepantes" estão na verdade CORRETOS na V3.0
   - Lição: Sempre validar fonte de referência!

### 🔄 O Que Ainda Precisa Melhorar (V4)

1. **Chunking para PDFs Longos (>300 páginas)**
   - Caso #3: 7007859-54.2010.8.26.0500 (356 pgs)
   - Chunks isolados confundem o LLM
   - Solução: Estratégia de chunking com overlap

2. **Validação de Sanidade Pós-Processamento**
   - Adicionar checks automáticos após extração
   - Alertar se Líquido > Bruto
   - Alertar se valor < R$ 100

3. **Melhorar Detecção de Verbas Adicionais**
   - Alguns PDFs têm verbas não discriminadas
   - Diferenças de R$ 100-300 podem ser taxas/correções
   - Solução: Parsing mais granular
