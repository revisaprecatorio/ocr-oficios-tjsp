# V2.7.3 - Fix Data Quality Issues (numero_ordem + cpf_sucessor)

**Data:** 2025-12-12
**Status:** ✅ Implementado

---

## 🎯 Objetivo

Resolver problemas críticos de qualidade de dados identificados na base após deployment V2.7.2:
1. **numero_ordem NULL** em processos válidos (não rejeitados/anomalias)
2. **cpf_sucessor incorretamente preenchido** com CPF do próprio credor
3. **habilitacao_herdeiros** não detectado quando deveria

---

## 🔍 Análise dos Problemas

### **Problema 1: numero_ordem NULL** (IDs 5, 7)

#### Caso 1 - CPF 10773800891 (Processo 0118712-69.2021.8.26.0500)
- **PDF:** 107 páginas total
- **Ofício:** páginas 0-10
- **PROCESSAMENTO:** páginas 95-97
- **numero_ordem real:** `4254/2022`

**❌ CAUSA RAIZ:**
```
DetectorProcessamento tinha limite de 50 páginas:
  - Busca iniciava na página 10 (após ofício)
  - Limite de 50 páginas → alcançava apenas até página 60
  - PROCESSAMENTO estava na página 95 → NÃO DETECTADO!
```

#### Caso 2 - CPF 13725004803 (Processo 0137634-56.2024.8.26.0500)
- **PDF:** 126 páginas total
- **numero_ordem real:** `50228/2025` (página 80)
- **Documento:** "CERTIDÃO DE PUBLICAÇÃO DE RELAÇÃO"

**❌ CAUSA RAIZ:**
```
Detector buscava apenas keyword "PROCESSAMENTO":
  - Página 80 continha "CERTIDÃO DE PUBLICAÇÃO" (não "PROCESSAMENTO")
  - Continha "Número de ordem: 50228/2025"
  - Mas NÃO FOI DETECTADO!
```

### **Problema 2: cpf_sucessor incorreto** (ID 13)

#### Caso 3 - CPF 93968396804 (Processo 0142161-51.2024.8.26.0500)

**Dados no banco:**
```json
{
  "credor_cpf_cnpj": "939.683.968-04",
  "cpf_sucessor": "939.683.968-04",  // ❌ ERRO: MESMO CPF!
  "habilitacao_herdeiros": false
}
```

**Evidência (ANEXO II página 77):**
```
Nome: Ana Maria Duarte Saad Castello Branco
CPF/CNPJ/RNE: 939.683.968-04
Os dados bancários informados são do advogado? Sim
CPF/CNPJ do titular da conta bancária indicada: 939.683.968-04
```

**❌ CAUSA RAIZ:**
```
LLM extraiu "CPF do titular da conta" e preencheu cpf_sucessor
  - Mas é o MESMO CPF do credor (939.683.968-04)
  - Isso NÃO é habilitação de herdeiros!
  - É apenas o CPF do próprio credor na conta bancária
```

## ✅ Soluções Implementadas

### **Fix 1: Remover Limite de 50 Páginas**

**Arquivo:** `app/detector_processamento.py`

**Antes V2.7.2:**
```python
def detectar_processamento(self, pdf_path: str, inicio: int = 0, limite: int = 50):
    fim = min(inicio + limite, total_paginas)  # ❌ Limitado a 50 páginas!
```

**Depois V2.7.3:**
```python
def detectar_processamento(self, pdf_path: str, inicio: int = 0, limite: Optional[int] = None):
    """V2.7.3 FIX: Limite padrão removido (None = busca todo PDF)"""
    fim = min(inicio + limite, total_paginas) if limite else total_paginas
```

**Impacto:** Agora busca até o final do PDF, não importa o tamanho!

### **Fix 2: Detectar CERTIDÃO DE PUBLICAÇÃO**

**Arquivo:** `app/detector_processamento.py`

**Antes V2.7.2:**
```python
def _eh_pagina_processamento(self, texto: str) -> bool:
    texto_upper = texto.upper()
    tem_titulo = "PROCESSAMENTO" in texto_upper  # ❌ Só detecta PROCESSAMENTO!
    return tem_titulo and (tem_depre or tem_numero_ordem)
```

**Depois V2.7.3:**
```python
def _eh_pagina_processamento(self, texto: str) -> bool:
    """V2.7.3 FIX: Detecta também CERTIDÃO DE PUBLICAÇÃO"""
    texto_upper = texto.upper()

    # PROCESSAMENTO (padrão original)
    tem_titulo = "PROCESSAMENTO" in texto_upper
    tem_depre = "DEPRE" in texto_upper
    tem_numero_ordem = "Nº DE ORDEM" in texto_upper

    # V2.7.3 FIX: CERTIDÃO DE PUBLICAÇÃO
    tem_certidao = "CERTIDÃO DE PUBLICAÇÃO" in texto_upper
    tem_numero_ordem_certidao = "NÚMERO DE ORDEM" in texto_upper

    # Aceitar se:
    # 1. PROCESSAMENTO + (DEPRE ou numero_ordem)
    # 2. CERTIDÃO + numero_ordem
    if tem_titulo and (tem_depre or tem_numero_ordem):
        return True

    if tem_certidao and tem_numero_ordem_certidao:
        logger.info("✅ CERTIDÃO DE PUBLICAÇÃO detectada com numero_ordem")
        return True

    return False
```

**Impacto:** Agora detecta numero_ordem em CERTIDÃO DE PUBLICAÇÃO!

### **Fix 3: Fallback Global de numero_ordem**

**Arquivo:** `app/detector_processamento.py`

**Novo Método V2.7.3:**
```python
def buscar_numero_ordem_global(self, pdf_path: str) -> Optional[str]:
    """
    V2.7.3 FIX: Fallback global - busca numero_ordem em TODO o PDF usando REGEX.

    Usado quando detectar_processamento() falha.
    Busca padrões:
    - "Nº de Ordem: XXXXX/YYYY"
    - "Número de ordem: XXXXX/YYYY"
    - "Número do Precatório: XXXXX/YYYY"
    """
    logger.info("🔍 V2.7.3: Iniciando busca GLOBAL de numero_ordem em todo PDF...")

    doc = pymupdf.open(pdf_path)
    total_paginas = len(doc)

    # Padrões para buscar
    padroes = [
        re.compile(r'Nº de Ordem:\s*(\d{1,5}/\d{4})', re.IGNORECASE),
        re.compile(r'Número de ordem:\s*(\d{1,5}/\d{4})', re.IGNORECASE),
        re.compile(r'Número do Precatório:\s*(\d{1,5}/\d{4})', re.IGNORECASE),
    ]

    # Buscar em TODAS as páginas
    for page_num in range(total_paginas):
        page = doc.load_page(page_num)
        texto = page.get_text()

        for padrao in padroes:
            match = padrao.search(texto)
            if match:
                numero = match.group(1)
                if self.validar_numero_ordem(numero):
                    logger.info(f"✅ V2.7.3 GLOBAL: numero_ordem encontrado na página {page_num + 1}: {numero}")
                    doc.close()
                    return numero

    doc.close()
    logger.warning("⚠️ V2.7.3 GLOBAL: numero_ordem NÃO encontrado em nenhuma página")
    return None
```

**Integração no Processador:**

**Arquivo:** `app/processador.py`

```python
# Detectar PROCESSAMENTO
pagina_proc, texto_proc = self.detector_proc.detectar_processamento(
    pdf_path,
    inicio=inicio_proc,
    limite=None  # V2.7.3: Buscar até o final do PDF (sem limite)
)

# V2.7.3: Variável para armazenar numero_ordem de fallback global
numero_ordem_global = None

if pagina_proc:
    if tracker:
        tracker.adicionar_resultado(f"PROCESSAMENTO: página {pagina_proc}", sucesso=True, nivel=1)
else:
    if tracker:
        tracker.adicionar_resultado("PROCESSAMENTO não encontrado", sucesso=False, nivel=1)

    # V2.7.3 FIX: Fallback global - buscar numero_ordem em TODO o PDF
    logger.info("🔍 V2.7.3: Tentando busca GLOBAL de numero_ordem...")
    numero_ordem_global = self.detector_proc.buscar_numero_ordem_global(pdf_path)
    if numero_ordem_global:
        logger.info(f"✅ V2.7.3: numero_ordem encontrado via busca global: {numero_ordem_global}")
        if tracker:
            tracker.adicionar_resultado(f"V2.7.3 GLOBAL: numero_ordem = {numero_ordem_global}", sucesso=True, nivel=1)
```

**Impacto:** Se PROCESSAMENTO não for encontrado, busca numero_ordem em TODO o PDF!

### **Fix 4: Validar cpf_sucessor != credor_cpf_cnpj**

**Arquivo:** `app/processador.py`

**Novo Validador V2.7.3:**
```python
# V2.7.3 FIX: Validar cpf_sucessor != credor_cpf_cnpj
if oficio_validado.cpf_sucessor and oficio_validado.credor_cpf_cnpj:
    # Normalizar CPFs para comparação (remover formatação)
    cpf_sucessor_limpo = ''.join(filter(str.isdigit, oficio_validado.cpf_sucessor))
    credor_cpf_limpo = ''.join(filter(str.isdigit, oficio_validado.credor_cpf_cnpj))

    if cpf_sucessor_limpo == credor_cpf_limpo:
        logger.warning(f"⚠️ V2.7.3: cpf_sucessor ({oficio_validado.cpf_sucessor}) "
                     f"é IGUAL a credor_cpf_cnpj ({oficio_validado.credor_cpf_cnpj}) → Zerando!")
        oficio_validado.cpf_sucessor = None
        oficio_validado.habilitacao_herdeiros = False
        logger.info("✅ V2.7.3: cpf_sucessor zerado (mesmo CPF do credor)")
```

**Impacto:** Evita falsos positivos de habilitação de herdeiros!

### **Fix 5: Atualizar Prompts LLM**

**Arquivo:** `app/processador.py`

**Método `_construir_prompt_llm` Atualizado:**
```python
def _construir_prompt_llm(
    self,
    texto_oficio: str,
    tem_anexo_ii: bool = False,
    tem_processamento: bool = False,
    numero_ordem_titulo: Optional[str] = None,
    numero_ordem_global: Optional[str] = None,  # V2.7.3 NOVO!
    oficio_rejeitado: bool = False,
    motivo_rejeicao: Optional[str] = None
) -> str:
    """V2.7.3: Adiciona numero_ordem_global como hint ao LLM"""

    # V2.7.3: Adicionar hint sobre numero_ordem se encontrado
    nota_numero_ordem = ""
    if numero_ordem_titulo:
        nota_numero_ordem = f"""
✅ NÚMERO DE ORDEM JÁ DETECTADO NO TÍTULO: {numero_ordem_titulo}
- Use este valor para o campo numero_ordem
"""
    elif numero_ordem_global:
        nota_numero_ordem = f"""
✅ NÚMERO DE ORDEM DETECTADO VIA BUSCA GLOBAL: {numero_ordem_global}
- Use este valor para o campo numero_ordem
- Foi encontrado em CERTIDÃO DE PUBLICAÇÃO ou outra seção do PDF
"""

    return f"""Você é um assistente especializado em extrair dados de Ofícios Requisitórios do TJSP.

{nota_rejeicao}{nota_anomalia}{nota_numero_ordem}

...
"""
```

**Impacto:** LLM recebe hint de numero_ordem encontrado via busca global!
